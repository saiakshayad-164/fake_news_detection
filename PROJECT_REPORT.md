# AI Lab Case Study Report: Fake News Detection

## 1. Objective
To design and implement a text-classification application that predicts whether a news article resembles Fake or Real examples in a labelled historical dataset, using NLP, TF-IDF and supervised machine learning.

## 2. Problem statement
Online information can contain misleading or fabricated stories. This project demonstrates how supervised text classification learns patterns from previously labelled examples and applies them to an unseen article. The output is a prediction, not independent proof of factual truth.

## 3. Dataset
The project uses the ISOT Fake and Real News Dataset, distributed as Fake.csv and True.csv. The ISOT dataset description states that real articles were collected from Reuters and fake articles from sources identified as unreliable. The data is historical and largely focused on political and world news. The loader downloads the source files on first use; raw files are not stored in GitHub.

## 4. Data preprocessing
1. Read the Fake and Real CSV files.
2. Assign the corresponding class label.
3. Replace missing title and text values with empty strings.
4. Combine headline and article body.
5. Normalize repeated whitespace.
6. Remove very short records.
7. Remove duplicate article text.
8. Save the cleaned dataset.

## 5. Feature extraction
TF-IDF (Term Frequency–Inverse Document Frequency) converts text into numerical features. The implementation uses word unigrams and bigrams, lowercasing, Unicode accent stripping, and a vocabulary size limit.

## 6. Algorithms
Two supervised algorithms are compared:
- Multinomial Naive Bayes, a probabilistic classifier commonly used for text features.
- Logistic Regression, a linear classifier that estimates class probabilities from text features.

Both use the same stratified 80:20 train-test split and TF-IDF configuration. Random seed: 42. The model with the higher macro F1-score is selected.

## 7. Evaluation
The training script calculates accuracy, macro precision, macro recall, macro F1-score, classification report, and confusion matrix. Actual values are written to outputs/metrics.json and outputs/classification_report.txt. The confusion matrix is saved to outputs/confusion_matrix.png. Scores are generated by running the project; this report does not invent results.

## 8. Application
The Streamlit application provides headline and article input, Fake/Real prediction, model confidence, model comparison, evaluation metrics, confusion matrix, and classification report. The interface uses a light theme.

## 9. Limitations
- Dataset labels and source composition may introduce bias.
- Historical data may not represent current events.
- The model learns textual patterns, not the factual truth of claims.
- Confidence is a model score, not factual certainty.
- Consequential claims should be checked against multiple reputable, independent sources.

## 10. Conclusion
This case study demonstrates an end-to-end supervised NLP workflow for binary news text classification, from labelled data preparation through model comparison, evaluation, and interactive prediction. It is an educational text-classification demonstration, not an authoritative truth detector.
